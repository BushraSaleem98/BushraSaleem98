# Stage 1 — Networking Fundamentals
**Reference:** `CYBER-ROADMAP-2025-FULL`  
**Goal:** Build strong networking knowledge required for cybersecurity roles.  
**Timeline:** (Dec-2025, TBD)

---

## 🎯 Objectives
- [ ] Understand OSI and TCP/IP models  
- [ ] Learn about protocols: DNS, DHCP, HTTP/HTTPS, TCP, UDP, NAT  
- [ ] Subnetting and IP addressing fundamentals  
- [ ] Learn VPNs, firewalls, and proxies  
- [ ] Perform basic network analysis using Wireshark
